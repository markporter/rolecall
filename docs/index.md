# RoleCall

RoleCall is a Bun-first config management & orchestration tool - an Ansible
alternative that runs as a single executable, both as a CLI (`rolecall playbook run …`)
and as an orchestrator server (`rolecall --serve`).

This user guide covers getting started, command reference, core concepts, best
practices, deployment, and how to contribute. It currently ships placeholder
content while the engine subsystems are being populated; expanded prose will
follow once real CLI behavior and README material are incorporated.

- **Guide** - install RoleCall, quickstart, and your first playbook: [Getting Started](/guide/install)
- **Reference** - commands, global options, and plugins: [Command Reference](/reference/command-reference)
